# 颱風假決策室

直接開啟 [index.html](index.html) 即可遊玩，不需要安裝或啟動伺服器。

- 十秒看完颱風前五天路徑，再根據三條可能路線及機率做決定。每局從八種前期路徑抽選，實際路徑也可能出現四種預測外轉向。
- 路徑播放完後，遊戲時間停在晚上 20:00，只給五秒宣布；猶豫和逾時會降低下期市長當選率。
- 電腦用滑鼠左鍵槌按按鈕，也可按 `A` 放假、`D` 不放；手機直接點按。手機上的 Threads 副螢幕可點右上角放大。
- 結局有 24 種新聞版本：放假／不放／逾時 × 晴天／風雨不大／暴風雨／傍晚才來的暴風雨，每種情境有兩個新聞角度。新聞顯示實際路線、天氣、市民反應及下期市長當選率。
- Threads 在五天路徑與決策倒數期間持續更新；每局隨機抽出貼文，支援捲動、按愛心，結局也有對應天氣與決策的留言。

室內場景、拳頭、決策按鈕與新聞照片為此遊戲製作的圖像素材。地圖海岸線以 [Natural Earth 10m physical vectors](https://www.naturalearthdata.com/downloads/10m-physical-vectors/) 為參考資料；這是遊戲模擬，非即時氣象預報。

Threads 貼文全是虛構角色與原創文字。語氣與關注點參考公開的[颱風假討論報導](https://www.ftnn.com.tw/news/559715)、[通勤與安全爭論](https://udn.com/news/story/120912/8119804)及[居家辦公討論](https://www.knews.com.tw/news/AC1DF76EE81716128BAE9621225D4AB4)。
